# RaineDev

RaineDev — третья раскладка веб-плеера musik в стиле Material You. Она использует общие API и логику воспроизведения. Логотип взят из Sirin Music.

Выбор: **Профиль → Интерфейс → RaineDev**. Настройка сохраняется в cookie этого браузера. Оригинальная раскладка и Mozgolika доступны в том же списке.

На ПК слева находится навигация, внизу — плеер. На телефоне разделы переключаются снизу, плеер расположен над ними. На главной отдельно показаны радио, настроения, миксы и любимые исполнители. На экране воспроизведения обложка и управление находятся рядом с очередью, текстом и объяснениями.

По умолчанию используется тёмная палитра с сиреневым акцентом. Сохранённая пользовательская палитра и настройка цвета от обложки продолжают работать. Клавиша `/` открывает поиск по библиотеке. Загрузка музыки доступна в боковом меню и из профиля.

Для выбора по умолчанию на сервере: `MUSIK_UI=rainedev`. Cookie браузера имеет приоритет. Без этой настройки сохраняется прежняя раскладка по умолчанию.

Файлы раскладки: `player/internal/static/rainedev.html` и `rainedev.css`, тексты уведомлений — в `rainedev.js`. Дополнительных внешних шрифтов, библиотек и сетевых сервисов нет.
